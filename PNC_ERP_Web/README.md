# PNC ERP — 차세대 웹 ERP 프론트엔드 (프로토타입)

ecount·더존 스타일의 웹 기반 ERP UI. **조회(inquiry) 기능 우선** 구현 — 현행 ERP 데이터를
차세대 스키마로 이관한 **실데이터**를 담아, 기존 ERP와 값이 일치하는지 대조·검증하는 용도.

## 실행 방법
- **가장 간단**: `index.html` 더블클릭 (별도 서버 불필요 — 실데이터가 `js/data.js`에 내장).
- 데이터 갱신: `scratchpad/export_web_data.py` 재실행 → `js/data.js` 재생성.

## 구성
| 파일 | 내용 |
|------|------|
| `index.html` | 셸 (헤더/사이드바/MDI 탭) |
| `css/app.css` | ecount/더존 스타일 |
| `js/app.js` | SPA 로직 + 조회화면 4종 |
| `js/data.js` | 실데이터 스냅샷 (PARTNER_ERP_TEST2) |

## 구현된 조회 화면
- **대시보드** — KPI(품목 24,093·거래처 356·BOM 8,500리비전·단가 126,889·경로 6,408) + 유형/분류 분포
- **품목 조회** — 검색·유형필터, 그리드 → 상세(매입처 N:M + 단가 시계열)
- **거래처 조회** — 업무분류 필터, 역할 N:M(매입·매출·가공외주) 배지
- **BOM 조회** — 리비전 이력 + 구성(사급 배지) + 3축/경로 설계 안내
