01

이 시스템을 짓는 두 개의 "왜"

기능이 아니라 손실이 출발점이다. 모든 설계는 이 둘로 환원된다.

기둥 I · 환율 손익

고환율 → 태국 조달이 적자

작년부터 태국법인에서 부품을 대량 조달했으나, 환율 급등으로 태국 조달이 큰 적자로 전환. 현행 시스템은 태국 부품을 마감 KRW로 고정 저장해 환율 시뮬레이션 자체가 불가능하다.

−737원/개 검증된 앵커 · AJR75563402 태국(F&T) 경로 실원가 손익

해법 — 경로별 손익을 금일 환율로 재평가해 "지금은 내수, 환율 내리면 태국" 을 정량 판단.

기둥 II · 사급 정합

사급 누수 → 손실로 묻힘

과거 업체 입고수량 > LG 리시빙 수량 gap이 재고관리 미흡으로 누락돼 전부 손실 반영. LG로부터 받는 사급, 업체로 불출하는 사급이 철저히 관리돼야 한다.

LG→PNC 원소재 사급 / 월
20~25억

해법 — 홉마다 수량·무게를 물리고, 초과입고 차단 + 자동 대사로 gap을 표면화(자동 손실반영 금지).

03

조달 프로파일 — 이 시스템의 심장

BOM(무엇으로)과 조달(누가·어디서)을 분리. 한 품목 = 1 BOM + 여러 프로파일. 프로파일만 갈아끼우면 원가·손익이 재계산된다.

프로파일 = 구매정책 컨테이너

담당자가 프로파일을 만들 때 정책을 사전 지정한다.

  • 공급 구분 · 자체 / 유상사급 / 매입
  • 거래처 · 리드타임 · 픽스 (절삭 3일 픽스, 리드 2~3일)
  • CAPA — 개발 시 이미 아는 생산능력 = 분할 상한
  • 배분 정책 — 기간별 배분율(단일 or 분할)
  • 사급 여부 · 부품별 · is_internal(내부용 벤치마크)

일원화가 기본, 이원화는 예외. 대부분 품목은 프로파일 1개 → 자동. 전략 품목만 담당자가 배분 결정(decision-by-exception).

발주 확정 화면 = 경로별 손익 비교

MRP가 순소요를 뽑으면, 화면에서 경로별 손익·리드타임을 보고 배분한다. 태국 칸엔 금일 환율 입력 → 즉시 재계산.

04

가격 2트랙 — 실적과 의사결정을 분리

원소재·태국 부품 모두 USD 원천이나 월 마감 때 KRW로 고정된다. 실적은 그 확정가로, 의사결정은 금일 환율로.

실적 · 손익 평가

월 마감 확정가 (locked)

이미 선적·입고된 것의 실제 landed cost. BL 시점 환율로 고정 = 실현 손익 계산에 정확. 현행 방식 유지.

운영 · 의사결정

원단가 × 금일 환율

USD 원단가를 보관하고, 변동 환율은 화면에서 사용자가 입력(what-if). DB에 수시 환율을 넣지 않는다. → 지금/예상 환율의 손익을 즉시 시뮬레이션.

필수 요건 — 태국(해외) 프로파일에 USD 원단가 보관. 동단가는 성분(단가·환율)이 남아 자동 재구성.

06

수량·사급 정합 — 4가지 통제

월 30억+ 사급이 걸린, 이 시스템에서 가장 큰 돈이 걸린 통제. gap은 자동으로 손실 처리하지 않고 반드시 원인을 추적한다.

1

입고 = 발주(PO) 매칭

발주 없는·초과 입고는 경고·차단(예외처리). 문제의 원천을 입구에서 막는다.

2

업체 입고 ↔ LG 리시빙 대사

gap 즉시 표면화. 자동 손실반영 금지 → 원인 추적 후 처리. LG 리시빙은 PU-SCS 다운로드로 확보.

3

동 무게 정합

LG 수령 = Σ업체 불출 = Σ입고 소비(부품 × BOM 동무게) = 납품에 실린 동. 차이는 재고 or 로스로 명확히 귀속.

4

단일 원장 · 4-way 매칭

자재·생산·사급 재고를 한 원장에서(누락 0). 발주–입고–리시빙–계산서 4자 자동 매칭.

08

구축 로드맵 — 금액 노출 우선순위

가장 큰 돈이 걸린 곳부터. 두 기둥 모두 현행 데이터로 시작 가능한 read-only 분석이 있다.

Phase 0 ✓

기반 — 완료

nx 통합 스키마 · 라이브 마이그레이션 · 원가엔진 검증 · 동무게 실증.

Phase 1 · 착수

두 개의 Quick-Win (read-only, 즉시 가치)

A. 조달 손익 비교 화면 — 경로별 손익 + 금일 환율 what-if. 검증된 엔진 위에 얹으면 되고, 새 데이터가 거의 필요 없다. 환율 문제 직격.

B. 수량·사급 정합 대사 리포트 — 업체 입고 vs LG 리시빙 vs 사급 불출 gap 표면화. 월 30억+ 노출 직격.

Phase 2

조달 정식화

프로파일 시드(현행 + 내부용 벤치마크) · 발주 확정(프로파일 배분) · 사급 불출 로직.

Phase 3

실행 파이프

LG 계획 업로드 → MPS → MRP 전개 → 발주 · 입고. 협력사 모바일 ASN/입고(전부서 실시간 공유).

Phase 4

마감 · 정산

하이브리드 중량정산 · 3/4-way 자동 매칭 · 계산서 정합 · 통합 마감.
