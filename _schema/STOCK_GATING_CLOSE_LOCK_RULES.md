# 재고 가용성 게이팅 + 마감 일자 잠금 — 전 도메인 공통 규칙 (정본)

> 작성 2026-08-19. 대표 지시: **마이너스 재고가 시스템에서 발생하지 않게** + **마감된 일자는 수정 못하게** — 생산·영업·자재 **전 프로그램에 동일 규칙**으로.
> 이 문서 = 흩어진 기록(주로 [[NX_STOCK_LEDGER_DESIGN]] · 코드 기구현분)을 **하나로 통합·정리**. 신규 구현은 여기 기준.
> 관련 durable: `NX_STOCK_LEDGER_DESIGN.md`(재고점 모델·posting), `TRANSACTION_CUTOVER_DESIGN.md`(컷오버).

---

## 0. 두 규칙 (한 줄 정의)
- **규칙 A — 재고 가용성 게이팅**: 어떤 차감(출고/소비/키팅/이동)도 **결과 재고가 음수가 되면 거부**. 앞 단계 재고가 없으면 다음 단계 불가.
- **규칙 B — 마감 일자 잠금**: **마감된 기간(≤마감일)의 거래는 생성·수정·삭제 불가**(생산·영업·자재 공통). MASTER 강행옵션은 정책.

## 1. 규칙 A — 재고 가용성 게이팅 (마이너스 원천차단)

### 1.1 단계 체인 (대표 지시 + ★생산 2공정 분리)
**생산은 2가지(PR_M_WORK): P2=가공 · P1=용접.** 따라서 체인은 5단계:
```
자재입고 → 키팅(준비) → [P2 가공] → [P1 용접/조립] → 출고
  └ 입고 안 된 품목은 키팅 불가
     └ 키팅 안 되면 가공실적 안 잡힘
        └ 가공(가공품) 없으면 용접/조립 실적 안 잡힘
           └ 용접(완성품) 없으면 출고 불가
역방향(취소/반품)도 동일 — 결과가 음수면 거부
```
재고점(STOCK_POINT, [[NX_STOCK_LEDGER_DESIGN]]): **MAT(자재) → RDY(준비) → PRD_G(가공품, P2·가공창고 P0001/11라인) → PRD_W/ASY(용접·완성, P1·S계열 라인) → 출하**. 사급=SAG.
- **P2 가공**: 자재(동파이프) 절삭/축관 → 가공품(반제품). 소비=자재/준비, 산출=가공품.
- **P1 용접/조립**: 가공품+부품 용접·체결·검사 → 완성품. 소비=가공품/부품, 산출=완성(ASY).
- 게이팅은 **각 공정 진입 시** 앞 재고점(가공은 자재/준비, 용접은 가공품) 가용검증.

### 1.2 공용 함수 (신설·통일)
```
assert_stock(cur, stock_point, key_dims, need_qty)
  현재고 = 원장 SUM(해당 재고점·품목·[파트/cust])   # nx.stock_ledger 파생 = 기초+ΣMAINT
  if need_qty > 현재고 + 허용오차:
      raise HTTPException(400, f"재고부족 ({품목} 가용 {현재고:g} < 필요 {need_qty:g})")
```
- 차감 쓰기의 **트랜잭션 내, 원장 INSERT 직전** 호출.
- 취소/역거래: 되돌린 뒤 재고가 음수면 거부(동일 함수, need=역수량).
- 현재고 정본 = **nx.stock_ledger STOCK_POINT별 SUM**(컷오버 전 미적재 구간은 레거시 대사로 보강 — [[TRANSACTION_CUTOVER_DESIGN]]).

### 1.3 기구현(참고) — 이미 있는 패턴을 표준으로
- `stock.py`(자재조정/출고): `재고부족 (가용 avail < qty)` 가드 有 → **이 패턴을 공용함수로 승격**.
- `prodwrite.py`(생산자재이동): `FROM파트 재고부족` 가드 有.

## 2. 규칙 B — 마감 일자 잠금 (전 도메인)

### 2.1 마감 단위 (실측 인프라 기준)
- **월마감(전역)**: `nx.stock_close(ym, close_flag)` — 공용함수 `_closed(cur, ymd)`가 이미 판정. **생산·영업·자재 공통**.
- **업체별 마감일**: `MAGAM`/`CM_M_CUST_MAGAM`(JUN_YYMM·JUN_MAGAM_DAY·MAGAM_DAY) — 매입/매출 정산 기준([[newerp-lgsagub-recvcompare]] 등에서 사용).
- **일마감(자재)**: 자재 일마감 스냅샷([[newerp-matclose-movavg]] nx.mat_stock_daily) — 확정일 이하 잠금(추후 연동).
- 레거시 3가드(월말 pu_t_month_stock·수불 pu_t_month_stock_wh·일마감 CM_M_DAILY_MAGAM) → **nx.stock_close/MAGAM로 통합**([[NX_STOCK_LEDGER_DESIGN]] §E).

### 2.2 공용 함수 (통일)
```
assert_open(cur, ymd, domain=None, cust=None)
  if _closed(cur, ymd):  raise HTTPException(400, f"{_ym(ymd)} 마감된 월입니다 — 수정 불가")
  if cust and 업체마감일 >= ymd: raise ...   # 업체별(매입/매출)
```
- **모든 쓰기(생성/수정/삭제)** 진입부에서 대상 일자 검증. 수정/삭제는 **기존 행 일자와 신규 일자 둘 다** 검증.

### 2.3 기구현(참고)
- `_closed(cur, ymd)` = `nx.stock_close WHERE ym` (common.py). 이미 `prodwrite`(생산·자재)·`sales`(매출)에서 호출.

## 4. 균일 적용 계획 (구현 순서 — 승인 후 하나씩)
1. **공용함수 2개 확정**(common.py): `assert_stock(...)`, `assert_open(...)`. 기존 stock.py 재고부족·`_closed` 패턴을 승격·통일.
2. **키팅**(kitting.py cell-confirm): 자재입고(MAT)/준비 재고 없으면 키팅 거부 + 마감잠금.
3. **생산실적 백플러시**(backflush.py): 준비(RDY)/자재(MAT) 없으면 실적 거부 + 마감잠금.
4. **출고/매출**(sales.py·saleout): 완성(ASY) 없으면 출고 거부(재고가드 전면) + 마감잠금 전면.
5. **도입·매입입고**(dopip): 마감잠금(입고는 재고가드 불필요).
6. **마감처리 자체**(purmagam/salemagam): 마감확정 후 해당기간 재편집 잠금.
7. 각 단계 **왕복검증**(정상/부족거부/마감거부) + 취소·반품 역가드.

## 5. 원칙 (사고 재발방지)
- 게이팅은 **트랜잭션 내**(검증→INSERT 원자성). 원장(stock_ledger) **무삭제**([[feedback-nx-ledger-no-mass-delete]]).
- 현재고 정본 = **nx 단일원장 파생**(드리프트 구조적 불가). 컷오버 전 미적재분은 레거시 대사 보강.
- 규칙은 **공용함수 2개**로만 존재 → 전 프로그램이 같은 함수를 호출 = **동일 규칙 보장**(중복로직 금지).
