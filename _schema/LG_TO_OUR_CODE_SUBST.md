# nx.bom 품번을 우리 BOM(레거시)로 정렬 — LG→우리 코드 치환

> 대표 지시(2026-08-24): **"LG BOM에서 우리 BOM 레거시로 바꿔야 해. 품번은 우리 BOM을 따라야 해."**
> nx.bom은 LG BOM Explosion으로 **최초 로드**했지만, 품번은 **우리 레거시 BOM**을 따라야 하고, 한번 바뀌면 그대로 유지. 컷오버 지연 원인 중 하나.

## 1. 문제 실측
- nx.bom(40,620 edge)은 현재 **child_code = LG 품번 100%**. 우리 BOM과 품번이 다를 수 있음.
- 예 AJR75563402: LG=`5006AR4091C`(Cap) ↔ 우리 BOM=`5006AR4091H`. 나머지 9개는 동일. **유일 차이가 품번(변형문자 C→H)**.
- 우리 BOM(품목 BOM관리 화면)은 `nx.bom_line`(미러)를 읽어 **이미 우리 품번(H)**. 문제는 nx.bom(LG측)만 C.

## 2. 이미 만들어 둔 엔진 = `nx.bom_merge_map` (18,519행)
- 컬럼: `doban·lg_part·lg_desc·lg_qty·leg_jadoban·leg_code·match_type`.
- **`lg_part`=LG품번 → `leg_code`=우리품번** 매핑. match_type: 정확 15,886 · 접미사 707 · 변형문자 683 · 용접봉 654 · LG신규 587 · 견적원가 2.
- 4규칙 정규화(정확/접미사-N/변형문자A·B/재귀깊은층) 내장. **세트입고 도번 1,294개** 범위로 구축(전 품목 아님).

## 3. 치환대상 = LG≠우리 = **56 LG품번** (대부분 정확일치는 이미 동일)
- **단일타겟 48** (LG품번→우리품번 유일, 전역 적용 가능):
  - 변형문자: 5006AR4091**C→H** · 4930A20053**A→B**(170도번) · 3A00375**B→P** · 4H00006C→A · 4H00049A→C 등
  - 접미사: RAC30599301→**-1**(635도번) · AJR76462621→**-IS** · 5014A20009A→**-C** · MJU62128503→**-01** 등
- **다중타겟 8** (도번별로 다름 → 전역 불가, 도번별 처리 필요·보류):
  - 3H00815J{H/D} · 3H01582A{C/E} · 3H01582B{C 187도번/A 77도번} · 3H01582D{A/C/E} · 5211A22074A{-1/-2/-3} · 5220AR3228Y{E/W} · 5410A30055D{B/G} · 5410A30055S{N/D}

## 4. 안전성 검증 (적용 전 필수, 완료)
- **치환 타겟(우리코드) 60종 전부 품목마스터(PR_M_ITEM) 실재** → 고아 위험 0.
- 현재 nx.bom LG코드 중 **MJU66108101은 마스터에 없는 고아** → 치환(→MJU66108101-1)하면 **수정됨**.
- nx.bom에서 이 56 LG코드 사용 edge = **4,064** (치환 영향 범위).

## 5. 적용 계획 (승인 후 · 가역)
1. **백업**: `nx.bom_bak_260824_lg2our` = nx.bom 전체 복사. + nx.bom에 `child_code_lg·parent_code_lg` 컬럼(원본코드 보존).
2. **단일타겟 48 전역 치환**: child_code/parent_code 모두, 원본은 `_lg` 컬럼 보존.
3. **검증**: AJR75563402 → 5006AR4091**H** 확인 · 잔여고아 0 · edge 무결.
4. **다중타겟 8 = 보류**(도번별, 이후 별도).
- **롤백**: `_lg` 컬럼으로 복원 or 백업테이블 복구.

## 6. 잔여 (전 품목 확장)
- merge_map은 1,294 세트도번만 커버(5,362 LG품번). nx.bom child_code 9,967종 중 4,605 미커버.
- 미커버 제품(AJR75563402 등)도 단일타겟 48은 전역이라 적용됨. 하지만 merge_map이 못 본 **추가 치환**이 있을 수 있음 → 전 품목 대상 **proper merge 엔진 재실행**(전체재귀+4규칙, 크루드 재유도 금지=10배 과다계상) 필요. 별도 단계.
