# 협력사견적(coop_quote) 재구성 정본 스펙 (2026-08-07)
> 어제~오늘 확립한 전 규칙. **이 스펙대로 견적서에서 1회 결정론적 재빌드**. 이후 개별 패치 금지 = 재빌드만.

## 0. 정본 소스 (단일)
- **견적서 = `협력 업체 견적 정리.xlsx`** (협력사별 시트, vendor 매칭).
  - 컬럼: col0=Assy · col3=원소재 · col5=외경 · col6=두께 · col7=길이 · col8=원소재비(=종전사급가) · col9=재료비 · col13=소요량.
  - **같은 원소재가 여러 협력사 시트에 다른 단가로 존재** → coop vendor에 맞는 시트값만 사용(첫값 금지).
- BOM 구성 = **CS_M_ITEM_BOM**(개발품목BOM 정본, USE_QTY=소요). 파일 소요=1은 단순화 오류.
- 마스터 = PR_M_ITEM (외경/두께/길이/METAL_GUBUN/IN_CUST_CODE/COST_GUBUN).

## 1. 역할(ptype) 분류
- **반제품**: BOM 자식 있음 → 전개.
- **용접봉**: 코드 RAC/BCUP.
- **동관/동관고강도**: METAL_GUBUN CU/고강도 AND **in_cust=owner(assy 소유협력사)이거나 빈값**(owner 직접가공). 고강도=동관고강도.
- **사급부품**: 동 파이프라도 **타 업체 공급(in_cust≠owner)** 또는 구매/매입(COST_GUBUN=2).
- **바레 원소재(BOM 자식 0)**: 품번 자체가 원소재 → 자기 자신을 제작동관 행으로.

## 2. 치수·개당중량
- 외경·길이 = 마스터 그대로.
- **두께 = 관경별 협의 표준**: 4.76·5.0·6.35·7.0·7.94·9.52 = **0.65** · 12.7 = 0.75 · 15.88·19.05 = 0.95 · 22.22·25.4·28.0 = 1.15 · 31.75 = 1.25. **소경 2.6·3.2 = 0.7 · 4.0 = 0.6(높은값)**. **고강도 = 마스터(BOM) 두께 그대로**.
- **uw(개당중량) = π(외경−두께)·두께·길이·8.94/1e6**.

## 3. 사급가·재료비
- **현재 사급가 = 20,000(일반CU) / 22,000(고강도)**.
- **종전 사급가 = 견적서 원소재비(vendor 매칭)**. 참고범위 CU ~7,550 / 고강도 ~12,500. 견적서에 없으면 종전 없음.
- **동관 재료비 = uw × 소요 × 사급가** (현재=20000/22000, 종전=견적서원소재비).
- **사급부품 재료비 = 최신 매입가(PR_M_ITEM_COST TAG1 대표, 2228제외) × 소요**.
- **용접봉 재료비 = 단가 × 소요**.
- **헤더 재료비 = Σ 부품 재료비**.

## 4. 판가·가공비
- **판가 = 실입고 거래가**(현재=최신, 종전=25/11 이하 최신 · 년말 가단가 제외). tag 9/S/C/G/H 포함.
- **가공비 = 판가 − 재료비**.
- **가공 세부(용접포인트·벤딩·확관 등)는 비움** — 직원 입력.

## 5. 신규(올해 시작) 처리
- **올해 납품 시작 = 종전(작년) 견적/실입고 없음 → 인상전(종전) 숨김**(is_new). 인상전 컬럼/재료비/가공비 표시 안 함.
- 판별: 견적서 종전 원소재비 없음 OR 종전 판가 없음.

## 6. 원칙
- **저장 파생값(종전/현재 재료비, 사급가)은 오염원** → 견적서에서 재빌드로만 채운다. 필드별 개별 수정 금지.
- 조립품(자식 있음)은 하위 리프 합, 바레 원소재는 자기행.
- 편집(직원): 역할 드롭다운·치수·소요·사급가 편집 → set-role/bom-save로 재계산.
