# 역할별 정본 필드 사전 (FIELD_CANON) — 동일 역할 = 동일 필드

> 목적: **같은 업무 역할이면 전 프로그램이 동일한 정본 필드를 읽는다.** "같은 개념인데 화면마다 다른 테이블/필드"를 없애 값 드리프트·혼동을 차단한다.
> 계기(2026-08-26): SUB 접미사가 품목마스터 2개(PR_M_ITEM 미러 vs nx.item 클린) 중 하나에만 적용돼 실원가 탭만 어긋남 → 필드 레벨 거버넌스 필요.
> 관계: 테이블 레벨 = `MIRROR_CLEAN_DUAL_TABLE_AUDIT.md` · 금지필드 = `DO_NOT_USE_FIELDS.md` · 하드룰 = `CLAUDE.md §1-9`(마스터 정본=클린본).
> ★작업 전 필독. 새 프로그램/엔진은 여기 정본 필드만 읽는다.

---

## 1. 프로세스 (필드 라이프사이클)

**동일역할=동일필드 확립:**
1. **정본 필드 등록** — 역할 → 정본 테이블.컬럼 (아래 §3 사전).
2. **전 프로그램 필드사용 전수감사** — 어느 코드가 어느 필드를 읽는지(grep) → 비정본 사용처 목록.
3. **이관** — 비정본 → 정본 (엔드포인트별 before/after diff0·옆에짓고).
4. **상시 감시** — sync 후 grep으로 비정본/금지필드 사용 자동검출(재발 방지).

**사용 안 하는(은퇴) 필드 처리 — 즉시 삭제 금지, 3단계:**
| 단계 | 조치 | 시점 |
|---|---|---|
| ① 은퇴 등록 | `DO_NOT_USE_FIELDS.md`에 `[금지 필드]→[정본 대체]→[사유]` | 즉시(문서) |
| ② 읽는 코드 이관 | 그 필드 읽는 코드 전부 정본으로 → 읽는 곳 0 | 점진·diff0 |
| ③ 물리 은퇴 | 미러 필드=**컷오버 때 미러 테이블째 은퇴** / nx 클린 미사용 컬럼=**승인 후 DROP**(CLAUDE §1-6) | 컷오버/승인후 |

---

## 2. 정본 원칙 (요약)
- **마스터 = 재구축 클린본**(CLAUDE §1-9): 품목=`nx.item` · 거래처=`nx.partner` · 단가=`nx.price_*` · 재고=단일원장/일마감. 미러(PR_M_ITEM·CM_M_CUST…)는 dbo repoint 호환용·은퇴 대상.
- **역할이 여러 개면 정본 필드도 여러 개** — 각 역할이 자기 정본만 읽음(중량 3역할이 대표 예, §3).

---

## 3. 역할 → 정본 필드 사전

### 3-1. ★중량 (3역할·grain 다름·각자 자기 자리) — 2026-08-26 파일럿
> "중량=원소재 소요량=동일축, 소스만 다름"([[newerp-weight-source-lg-vs-actual]]). 세 값이 다른 이유=**치수·근거 소스가 다름**(우리 0.70 / 협의 0.65 / LG). 실측 확정: std≈fin(우리/LG표준치수), coop=협의0.65, LG인증=별개 grain.

| 역할 | 정본 필드 (위치) | grain | 우리BOM 유입 | 용도 | 근거 |
|---|---|---|---|---|---|
| **우리 실측** | `bom_dim.fin_weight`(=nx.item.net_weight, 97%일치) | 부품 개당중량 | ✅ 정본 | 원가·소요·중량가공비 | 동관공식 π(D−T)T·L·8.96, dim_src='견적원가(우리)' |
| **LG 인증** | `nx.lg_bom`(unit='KG' 원소재 Tube,Raw 행 qty) / `nx.bom` 원소재 edge | 원소재 소요 KG(BOM레벨) | ❌ **안 넣음**(LG BOM에 그대로·참조) | **사급 LME 차액 정산** | 사용자 확정 2026-08-26 "우리 BOM에 넣을 필요 없음". 예 MJU66386101=3.1975KG |
| **협력사 정산** | `coop_quote_part`(unit_wt, 협의0.65) / `bom_dim.coop`-geom | 부품 개당중량 | 협력사 마스터 | 협력사 원소재 수불정산(차액) | [[newerp-coop-rawmat-settlement]] 협의두께 |

**규칙**: 원가엔진=fin(우리) / 사급LME=nx.bom edge(LG) / 협력사정산=coop. **서로 안 섞음**. 은퇴대상: 원가엔진이 `PR_M_ITEM.ITEM_WEIGHT` 직독하던 것 → `bom_dim.fin_weight`(=nx.item.net_weight)로 통일(우리 실측 정본).
**미확정**: 협력사 개당중량 정본이 coop_quote_part인지 bom_dim.coop인지(둘 다 협의0.65) — 협력사 정산 도메인에서 확정.

### 3-2. 품목 식별·표시 (MIRROR_CLEAN §1 쌍1)
