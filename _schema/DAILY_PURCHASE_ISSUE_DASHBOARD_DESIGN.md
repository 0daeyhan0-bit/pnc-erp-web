- **상반기 = 1~15일 / 하반기 = 16~말일**.

## 블록 ① 매입 / 불출 / 실매입 (구분별 · 컬럼=누적|당일|총)
- ❌ 누계일평균·점유율 제거.
- **매입 원천 = 확정입고집계표**(기존화면): `PU_T_STOCK_MAINT`(tag 9/S/C/G/H) + `PU_T_STOCK_MAINT_C`(tag P), **마감기준**(업체별 마감일), by 거래처분류(=매입유형).
- **불출 원천 = 자재불출집계표**(기존화면): `PU/SA_T_STOCK_MAINT` + `PU_T_STOCK_MAINT_C`, **마감기준**, by 매입유형.
- 둘 다 **마감기준**(입고/불출기준 아님). 기존 백엔드 로직 재사용 예정.
- **구분(매입유형)**: 유상사급-원재료 · 유상사급-부품 · 절삭-원자재 · 설치-원자재 · 절삭-협력사 · 절삭-부자재 · 설치-부자재 · 소모품 · 이지링크.
- **★① 매입 = 확정입고집계표(당사ERP) 전체**(2026-08-18 사용자확정, 원리포트 매입=당사ERP). OSP 아님. OSP는 ④비율·D대사 전용(LG전산).
- **유상사급 분리(확정입고 안에서)**:
  - **유상사급-부품** = 확정입고 거래처분류 '유상사급' (현재 리포트 '1 유상사급' 1,372,406,329 = 부품).
  - **유상사급-원재료** = 확정입고 **사급 동 원소재 거래처**(LS메탈-사급 2237·HAILIANG-사급 2238 등) — 현재 '4 절삭-원자재'에 섞여있음 → **거래처→매입구분 매핑**으로 떼어냄. 절삭-원자재는 그만큼 감소.
- **실매입 = 매입 − 불출**(구분별). 음수 가능(불출>매입).
- **일단위(확정)**: 조회일 선택 → **누적 = 마감일 월초~조회일**, **당일 = 마감일=조회일**분. 둘 다 마감기준.
  - 구현: 확정입고집계표/자재불출집계표의 마감기준 집계에 **마감일 범위(월초~조회일) 필터** 추가.

## 블록 ② 매입비율 요약
- 기준 분모 = **LG매출액(총) = ⑤ 현매출(합계) = 현매출절삭+현매출설치**.
- 행: 매입 / LG매출 · 실매입(조정전) / LG매출 · 실재고(조정후) / LG매출.
- **실재고(조정후) = 실매입(조정전) − 재고조정**. (예시 재고조정 −75,452,082 → 실재고 증가)

## 블록 ③ 재고조정 = Σ버킷(조회일재고 − 전월기말재고)
- 버킷 4개(전부 기존화면 재사용):
  - 용접재고(BOM풀기) = 생산재고조회(용접·BOM풀기)
  - 가공재고 = 생산재고조회(가공)
  - 영업재고 = 제품재고조회
  - 자재재고 = 자재수불장
- **전월기말재고 = 조회월 기초재고**(기존 재고화면의 기초재고 컬럼).
- **조회일 재고(월중)** = 기초 + (월초~조회일 입출고) → **원장 날짜컷 로직 추가 필요**(현 화면은 월전체 기준).

## 블록 ④ 일단위 사급매입 ÷ 절삭매출 비율 (실측완료)
- 원소재매입(OSP TUBE)/절삭매출 · 사급부품매입(OSP non-TUBE)/절삭매출.
- 매입 = `nx.lg_sagub_actual`(원소재=TUBE, 부품=non-TUBE), 일자별 amt.
- 절삭매출 = `nx.SA_T_LG_RECEIVING_DTL` 금액(C−R) 中 품번='절삭'.
- 실측(260801~18): 절삭매출 1,193,780,857 · 원소재 28.9% · 부품 84.9%.

## 블록 ⑤ 매출요약 (상반기 | 하반기 | 합계 · 원단위)
- **현매출(절삭/설치)** = 리시빙(SA_T_LG_RECEIVING_DTL), 품목구분 절삭/설치. 상=1~15, 하=16~말.
  - 현매출(합계) = 절삭+설치 = ②의 LG매출액.
- **추가매출(절삭/설치)** = 영업예상매출현황(**영업 예상매출**, 차감후), 절삭/설치 분리.
- **사급예상금액 → 부품/원소재 분리**:
  - **예상사급부품** = 영업예상매출현황(**예상 LG사급금액**, 차감후) 자동.
  - **예상원소재** = **사용자 수기입력**(자동 원소재계산은 과소로 기각 이력 [[newerp-sagub-forecast]]). → nx 입력테이블(예 `nx.mgmt_forecast_manual`: ym, half(상/하), item_type='원소재', amt) + 화면 편집.
- **유상제외**(★화면 표시 안 함·계산 중간값) = **총매출 − 사급예상금액** (총매출=현매출합계+추가매출절삭+추가매출설치).
  - Excel: `SUM(J23:J25) − J26`. 검증: 상 1,943−1,252=691 · 하 3,791−1,700=2,091 ✔
- **내수금액** = **리시빙에서 내수 매출 직접**(비율 미적용, N21 폐기). 리시빙관리 내수/수출 필터의 '내수'분.
- **LG입금 예상금액**(←"부가세포함" 개명) = **(내수금액 − 사급예상)×10% + 사급예상**. Excel: `(J28−J26)*10% + J26`.

**⑤ 행 순서(최종)**: 현매출(절삭)·현매출(설치)·현매출(합계)·추가매출(절삭)·추가매출(설치)·사급예상금액[부품+원소재]·[유상제외=숨김]·내수금액·LG입금 예상금액.

## 블록 D 유상사급 대사 (당사ERP vs LG전산) — 2026-08-18 확정
- **당사ERP = 확정입고**(유상사급 매입) / **LG전산 = LG OSP**(nx.lg_sagub_actual). **두 소스 분리**.
- 행: LG전자(전산)=OSP · 당사ERP=확정입고 · **차액=당사ERP−LG전산**(예 1,372,406,329−1,222,784,515=149,621,814).
- 하단 사급실적표: 유상사급 상반기(LG)/하반기(LG)=OSP · LG절삭매출(리시빙 절삭) · 비율=사급/절삭매출(=④ 사급율).
