## 방법 = 데이터 기반 (추측 최소화)
- **uw 1순위 = PR_M_ITEM 마스터 geom** = (외경−두께)×두께×π×길이×비중/1e6 (확정입고명세서 SP `_receiptdetail`와 동일 산식). 비중=CM_M_MASTER_DETAIL PR019.
- 파일 개당중량과 **교차검증**: 삽입 435건 중 **363건이 마스터geom=파일 일치(±15%)** = 고신뢰. 나머지 마스터차이 31 / 파일only 41(마스터無, 주로 +용접링).
