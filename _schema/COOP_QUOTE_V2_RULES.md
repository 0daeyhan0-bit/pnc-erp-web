### ★ 사급부품 파싱 = 마커 위/아래 둘 다 확인 (필수)   ✅확정 (2026-08-08, COOP_QUOTE_MATCOST_RULES §2-8·2-9 승계)
- **사급부품은 견적서 col6(c6) 마커 "사급가" 로 표시됨.** 이 마커가 **1행(한 행)** 또는 **2행 중 위/아래** 어디에도 올 수 있음.
  - **1행 케이스**: 치수·사급가·재료비 한 행 (대원 등).
  - **2행 케이스**: "사급가"(값행)가 **위**(예 3H00815H=24000 위 / 명진 5210A22271A) 또는 **아래**(대원 일부)에 옴. 치수 detail 행은 별도.
- **파서는 마커를 위·아래 양쪽에서 찾아 결합해야 함.** 한 행만 보면 "동관 사급가빈값"으로 오분류(반복 실수).
- **그런 부품은 꼭 확인.** (V2 재료비는 DB 판매단가로 가지만, 분류·가공비·커팅추가가공 판정에 이 마커가 필요)

### ★ 왜 사급부품을 꼭 확인해야 하나 (배경)   ✅ (2026-08-08)
- **우리는 최신 견적부터 정리** (최신월→과거, 견적서 로그 아래=최신).
- **최근 추세 = 사급부품 → 업체 자작(자체제작) 전환이 많음.** 자작 = 업체 직접생산 = **원소재 수불 대상**(규칙③, 목적2 정산).
- → "사급부품처럼 보이는 것"도 실제 **자작으로 바뀐 것**일 수 있음. 놓치면 **수불 정산에서 누락**.
- BOM 단가구분이 정답이지만, **담당이 거래처만 바꾼 stale**(3:소재단가+1:사내인데 거래처가 '가공' 아님)도 있으니 검증. 이런 건 레거시를 2:외주로 정정(진행됨).

## 규칙 ② 인상후 재료비 변환 · 사급부품 가격읽기 · 가공비 과도인상 분석   ✅확정 (2026-08-08)

### 분석 목표 (정본 §0 · §2-10 재확인)
- 원소재(동) 사급가 **인상이 손익에 미치는 영향 추적**.
- **입고가(매입단가) = 견적가 + 조정가** (우리가 실제 지불).
- **총가공비 = 입고가 − 재료비**.
- **손익분석 = 재료비 인상분 vs 입고가 인상분 비교 → 과다/과소 조정(과도 가공비/역마진) 탐지.** ← 프로젝트 원래 목표(목적1).

### 규칙
- **(a) 인상전 값이 있으면 → 재료비를 인상후(현재 사급가 20,000/22,000)로 변경해서 본다.** (동관 = 중량×인상후사급가)
  - 인상전 없으면 비교 안 함(규칙①·정본 원칙).
- **(b) 사급부품 = 인상전·인상후 가격을 둘 다 DB에서 읽어온다.** ✅확정 (2026-08-08)
  - 품목단가관리 판매단가(PR_M_ITEM_COST, COST_TAG='S'). 인상전=종전(≤251130 최신) / 인상후=최신(≤적용월). 중량계산·역산 안 함.
  - **5220A90008Y(사급밸브)도 이 규칙 적용** — 견적서 19,243/현재 11,948을 임의로 쓰지 말고 **DB 판매단가 종전/최신**을 읽는다.
  - **인상후 < 인상전(인하)도 정상** ✅ — 5220A90008Y 19,243→11,948 = **밸브 소재 변경으로 가격 인하** (정상, 오류 아님).
- **(c) 가공비 = 견적서(c39) 그대로.** ✅확정 (2026-08-08) — 입고가−재료비 아님. 견적서 공정별 가공비를 사용.

## 규칙 ③ 부품 분류 (소재단가 동관 3분류)   ✅확정 (세션 확립)

레거시 BOM **단가구분(COST_GUBUN)** + **생산구분(MAKE_TYPE)** + **거래처(IN_CUST_CODE)** 로 판정.

### ★ 결정 트리 (단가구분 먼저)   ✅확정 (2026-08-08)
1. **단가구분 "구매단가"(2) / "사급단가"(1)** → 그냥 **사급부품 프로세스**(DB 단가 읽기). 특별처리 없음.
2. **단가구분 "소재단가"(3)** → 아래 3분류로 판정 (이게 꼭 확인해야 하는 케이스).

**소재단가 동관 (COST_GUBUN=3 + METAL='CU'/'고강도') → 3분류:**

| 조건 | 분류 | 재료비 |
|---|---|---|
| 생산 1:사내 + 판매단가 有 | **사급** | 판매단가 × 소요 (우리가 커팅해 판매) |
| 생산 2:외주 + 거래처 = **처리중 업체**(예 233 썬텍) | **수불(자작/제작동관)** | 중량 × 사급가 (그 거래처가 직접생산 = 원소재 수불대상) |
| 생산 2:외주 + 거래처 = **다른 업체** | **사급부품 프로세스**(그 업체에서 받아옴) | **DB 판매단가** 종전/최신 (매입가 아님) |

> ✅ 거래처=다른업체면 그 업체에서 받아올 확률 높음 → 사급부품 프로세스(DB 판매단가). (기존 "사급받음=매입가"에서 **판매단가로 정정**, 2026-08-08)
> ✅ 자작(수불) 처리 = 치수 계산 + 소요량 + 원소재가격(인상전=견적서 사급가<인상후가 / 인상후=20,000·22,000). **치수 못 찾으면 BOM 치수**(규칙①).

- **외주(2)는 항상 2가지 중 하나**: ⓐ 그 업체로부터 **사급받음**(매입) 또는 ⓑ 외주처 **자체제작(동 수불대상)**. (사용자 확정)
- 견적서에 "사급"으로 파싱된 것도 **해당 업체가 그 조립업체면 자체제작(수불)**. (사용자 확정)

**기타 단가구분:**
- **1:사급단가** → 사급 (단가 × 소요)
- **2:구매단가** → sg='910' 이면 **용접봉**, 그 외 **사급부품** (매입가 × 소요)
- **5:직납** → 제외 (하위 안 담음)

### 자작(自作) 정의   ✅확정 (사용자)
- **자작 = 업체가 직접 생산.** 기존엔 사급부품(우리가 소재 주고 매입)이었으나, 나중에 업체가 **직접 제작**으로 전환한 것.
- → **원소재(동) 수불 대상.** (목적2 월 수불 정산에 포함)
- **판정: 3:소재단가 + 2:외주 = 확실한 자작.**
- **stale 케이스**: 3:소재단가 + 1:사내인데 **거래처가 '가공'(사내 가공반 2000)이 아닌** 외부업체 = 담당이 거래처만 바꾼 자작 → **레거시를 2:외주로 정정**(사용자가 수정). 화면 거래처 = f(생산구분): 1:사내→"가공", 2:외주→IN_CUST.

### 컷팅만 / 가공컷팅   ✅확정 (사용자)
- **수불 대상 아님.** 우리가 커팅(면취)해서 **판매**하는 형태(사급부품처럼 처리).
- 견적서 길이 blank → 재료비 0 (컷팅만).

### 커팅+추가가공 (예 MJU65512602)   ✅확정 (2026-08-08)
- **우리가 커팅만 해서 협력사(썬텍) 주고 → 협력사가 추가가공해서 넣는 부품.**
- **재료비 = DB 판매단가** (사급부품처럼, 종전/최신).
- **가공비 = 견적서 "가공 컷팅" 행의 합계(c43)** — 예 196. (c39 가공비열 169.87 아님, **합계 196** 사용)
- **무상사급 아님 → 이 품번 가격 = 사급비(재료비) + 가공비(196).** 예 12,037 + 196 = 12,233. (재료비도 청구, 가공비도 붙음)
- 견적서 형태: 윗줄=동관 치수+사급가, 재료비 0 / 아랫줄=마커 "가공 컷팅"+합계.

## 규칙 ④ 견적서 ↔ BOM 매칭   ✅확정 (사용자, 2026-08-08 갱신)

- **오타 처리 = BOM 기준.** ✅확정 (2026-08-08): 견적서 코드가 BOM 구성과 다르면(예 견적 `MJU55479901` vs BOM `MJU66479901`) = 담당자 오타. **BOM 구성을 정답으로 보고**, 같은 SUB 블록에서 코드매칭 안 된 견적서 동관 행을 그 BOM 동관에 붙인다(오타쌍, 플래그·리포트).
  - 이유: BOM이 실제 구성. 견적서 코드 오타에 흔들리지 않게 BOM을 기준으로.
  - 오타쌍은 리포트로 출력 → 사용자가 견적서도 고치면 더 깔끔(선택).

## 규칙 ⑥ 용접봉 = 완제품(c1) 단위 매칭   ✅확정 (2026-08-08)
- **용접봉(Solder)은 완제품(c1) 견적 블록에 1건, 여러 SUB가 공유.** 견적서에서 용접봉 행의 c2가 공란이라 직전 c2로 오귀속되기 쉬움.
- → SUB(c2) 블록에 용접봉 없으면 **완제품(c1, sub의 앞토큰) 블록에서 용접봉을 찾는다.** (예 AJR30037603-20-2: c1="AJR30037603,4" 공유 용접봉)
- 매칭 실패로 결측되면 그 SUB는 용접봉 수불 누락 → 리포트.

## ★ 매칭 정밀화 (오타/SUB)   ✅확정 (2026-08-08)
- 견적서 매칭 = **SUB(c2) 정밀** + 완제품 입고 시 **SUB 접두어**로 BOM겹침 최다 블록 선택. (c1 병합은 서로 다른 SUB 오염 → 폐기)
- **오타 페어링은 치수(Φ+길이) 근사 일치할 때만.** 불일치면 미해결로 두고 인상전 공란+플래그(틀린 값 넣지 않음). 커팅추가가공/마커행은 페어링 후보 제외.

## 규칙 ⑤ 실사용 BOM 전개 (이중계상 방지)   ✅확정 (세션 검증)
- BOM 전개 시 **매입/사급/소재단가/직납(단가구분 1·2·3·5) = leaf** → 담고 전개 중단.
