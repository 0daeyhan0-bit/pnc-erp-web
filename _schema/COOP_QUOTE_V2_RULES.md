## 견적서 파싱 규칙 (엑셀 컬럼 구조) — 실측 해독·검증완료 (2026-08-08)

- **부품 1개 = 2줄** (윗줄 = 치수·원소재비·재료비·공정횟수 / 아랫줄 = 재료비율·공정별 금액·가공비·합계)

**컬럼 맵 (1-indexed, 헤더 R4 기준)**

| 열 | 의미 | 열 | 의미 |
|---|---|---|---|
| c1 | 완제품(PART NO 1) | c17~c38 | **공정별**(컷팅·면취·B/D·CNC·딤플·벌징·원교정·피어싱·압착·T뽑기·후레아·축확관·실링·망삽입·막음·코킹·세척·용접·부삽입·교체·수몰검사·포장) |
| c2 | 변형/SUB(PART NO 2) | c39 | **가공비(합)** |
| c4 | 원소재 코드 | c40 | 일반관리비 |
| c6/c7/c8 | Φ / T / L (또는 c6=마커) | c41 | 운반비 |
| c9 | **원소재비(사급가/kg)** | c42 | 이윤 |
| c10 | **재료비** | c43 | **합계(견적가)** |
| c12 | 재료비율 | c14 | 소요량 |

- **c6 마커**: "사급가"→사급부품/용접봉 · "기존가"→기존가 매핑 · "컷팅만/가공컷팅"→우리가 커팅해 판매 · 파이수치→동관
- 길이 blank → 재료비 0 (컷팅만)

**검증된 계산식 (AJR77188801-20-1 실측 일치)**
- 동관 재료비(c10) = geom(Φ,T,L) × 원소재비(c9). (단 V2는 규칙①대로 Φ·L=BOM, T=협의)
- **합계(c43) = 재료비 + 가공비(c39) + 일반관리비(c40) + 이윤(c42)**  (동관: 746+68.6+57.0+10.0=881 ✓ · 993+71.9+74.5+11.7=1150 ✓)
- **용접봉**(RAC): 재료비 = 사급가(c9=21,100) × 용접봉소요(c14) = 60 · 가공비(c39=149.1) 별도 · 합계=246
- **사급부품**(1줄): c9=c10=합계 = 사급단가 (예 5220A90008Y=19,243)

> ⚠️ 파싱 함정(반복 실수): 메모·재료비율이 **아랫줄 c6**에 올 수 있음. 데이터(치수·원소재비)는 **윗줄**. 아랫줄만 보면 오판.

## 규칙 ② 인상후 재료비 변환 · 사급부품 가격읽기 · 가공비 과도인상 분석   ✅확정 (2026-08-08)

### 분석 목표 (정본 §0 · §2-10 재확인)
- 원소재(동) 사급가 **인상이 손익에 미치는 영향 추적**.
- **입고가(매입단가) = 견적가 + 조정가** (우리가 실제 지불).
- **총가공비 = 입고가 − 재료비**.
- **손익분석 = 재료비 인상분 vs 입고가 인상분 비교 → 과다/과소 조정(과도 가공비/역마진) 탐지.** ← 프로젝트 원래 목표(목적1).

### 규칙
- **(a) 인상전 값이 있으면 → 재료비를 인상후(현재 사급가 20,000/22,000)로 변경해서 본다.** (동관 = 중량×인상후사급가)
  - 인상전 없으면 비교 안 함(규칙①·정본 원칙).
- **(b) 사급부품 = 인상전·인상후 가격을 둘 다 DB에서 읽어온다.** ✅확정 (2026-08-08)
  - 품목단가관리 판매단가(PR_M_ITEM_COST, COST_TAG='S'). 인상전=종전(≤251130 최신) / 인상후=최신(≤적용월). 중량계산·역산 안 함.
  - **5220A90008Y(사급밸브)도 이 규칙 적용** — 견적서 19,243/현재 11,948을 임의로 쓰지 말고 **DB 판매단가 종전/최신**을 읽는다.
  - **인상후 < 인상전(인하)도 정상** ✅ — 5220A90008Y 19,243→11,948 = **밸브 소재 변경으로 가격 인하** (정상, 오류 아님).
- **(c) 가공비 = 견적서(c39) 그대로.** ✅확정 (2026-08-08) — 입고가−재료비 아님. 견적서 공정별 가공비를 사용.
  - (원소재 무관하게 가공비는 견적서 값. 목적1 = 이 가공비가 과도하게 인상됐는지 분석)

## 규칙 ③ 부품 분류 (소재단가 동관 3분류)   ✅확정 (세션 확립)

레거시 BOM **단가구분(COST_GUBUN)** + **생산구분(MAKE_TYPE)** + **거래처(IN_CUST_CODE)** 로 판정.

**소재단가 동관 (COST_GUBUN=3 + METAL='CU'/'고강도') → 3분류:**

| 조건 | 분류 | 재료비 |
|---|---|---|
| 생산 1:사내 + 판매단가 有 | **사급** | 판매단가 × 소요 (우리가 커팅해 판매) |
| 생산 2:외주 + 거래처=조립업체(예 233 썬텍) | **수불(자작/제작동관)** | 중량 × 사급가 (업체 직접생산 = 원소재 수불대상) |
| 생산 2:외주 + 거래처≠조립업체 | **사급받음(매입)** | 매입가 × 소요 |

- **외주(2)는 항상 2가지 중 하나**: ⓐ 그 업체로부터 **사급받음**(매입) 또는 ⓑ 외주처 **자체제작(동 수불대상)**. (사용자 확정)
- 견적서에 "사급"으로 파싱된 것도 **해당 업체가 그 조립업체면 자체제작(수불)**. (사용자 확정)

**기타 단가구분:**
- **1:사급단가** → 사급 (단가 × 소요)
- **2:구매단가** → sg='910' 이면 **용접봉**, 그 외 **사급부품** (매입가 × 소요)
- **5:직납** → 제외 (하위 안 담음)

### 자작(自作) 정의   ✅확정 (사용자)
- **자작 = 업체가 직접 생산.** 기존엔 사급부품(우리가 소재 주고 매입)이었으나, 나중에 업체가 **직접 제작**으로 전환한 것.
- → **원소재(동) 수불 대상.** (목적2 월 수불 정산에 포함)
- **판정: 3:소재단가 + 2:외주 = 확실한 자작.**
- **stale 케이스**: 3:소재단가 + 1:사내인데 **거래처가 '가공'(사내 가공반 2000)이 아닌** 외부업체 = 담당이 거래처만 바꾼 자작 → **레거시를 2:외주로 정정**(사용자가 수정). 화면 거래처 = f(생산구분): 1:사내→"가공", 2:외주→IN_CUST.

### 컷팅만 / 가공컷팅   ✅확정 (사용자)
- **수불 대상 아님.** 우리가 커팅(면취)해서 **판매**하는 형태(사급부품처럼 처리).
- 견적서 길이 blank → 재료비 0 (컷팅만).

## 규칙 ④ 견적서 ↔ BOM 매칭   ✅확정 (사용자, 2026-08-08 갱신)
- **1순위: 품번(코드) 매칭** (같은 SUB 블록 내).
- **오타 처리 = BOM 기준.** ✅확정 (2026-08-08): 견적서 코드가 BOM 구성과 다르면(예 견적 `MJU55479901` vs BOM `MJU66479901`) = 담당자 오타. **BOM 구성을 정답으로 보고**, 같은 SUB 블록에서 코드매칭 안 된 견적서 동관 행을 그 BOM 동관에 붙인다(오타쌍, 플래그·리포트).
  - 이유: BOM이 실제 구성. 견적서 코드 오타에 흔들리지 않게 BOM을 기준으로.
  - 오타쌍은 리포트로 출력 → 사용자가 견적서도 고치면 더 깔끔(선택).

## 카테고리별 처리 (견적서 c6 마커 / 담당자 표현) — 정본 COOP_QUOTE_MATCOST_RULES.md 상세

- **사급부품**("사급가", 1줄) = 품목단가관리 판매단가(S) 읽기. 인상전=종전(≤251130)/인상후=최신. 거래처=견적업체(직거래 제외). 변형 base묶음+변형매칭.
- **기존가/확정가/협의가** = 그 품번의 상세 동관 견적행(치수+사급가)으로 매핑해 계산.
- **자작 = 수불대상** ✅확정 (2026-08-08). 업체 직접생산 = 동 원소재 수불(중량×사급가). 규칙③ 적용. (v1 문서의 "자작=자체수급 c10고정"은 V2에서 폐기 — 자작은 수불로 통일)
- **무상사급** = 소재 무상제공+밴딩만. **재료비=0**, 인상전=인상후=0.
- **용접봉** = **사급가 × 소요량** ✅확정 (2026-08-08). 소요량은 견적서(c14)에서 받음. 예 21,100 × 0.00284758 = **60**. (구매단가×BOM중량=216 아님). 공정종속(BOM에 없음), 인상없음(인상전=인상후).
