# 협력사견적 재료비 처리 규칙 (인상전 / 인상후)

> 사용자와 **하나씩 확정하며 기록**하는 살아있는 문서. 확정 안 된 건 ❓, 확정된 건 ✅.
> 작성 시작: 2026-08-05

## 0. 목적 / 배경
- 협력사견적관리 화면에서 **재료비 = 인상전(종전) vs 인상후(현재)** 비교.
- 원소재(동) 사급가 인상이 **손익**에 미치는 영향 추적 (사급가를 낮게 주면 손익 문제).
- **원칙: 역산(재료비÷중량) 하지 않는다.** 견적서에 있는 값을 그대로 쓴다.

## 1. 견적서 파일 구조 (협력 업체 견적 정리.xlsx)
- 헤더 행4. 데이터 행5~. 시트명 = 업체.
- col2/col0 = 상위 ASSY(PART NO), col3 = 단품 품번
- col5 = 외경 **또는 텍스트("사급가"/"기존가")**, col6 = 두께, col7 = 길이
- col8 = 원소재비, col9 = 재료비, col13 = 소요량

## 2. 부품 종류별 처리 규칙

### 2-1. 사급부품 (견적서 col5 = "사급가")   ✅확정 (2026-08-05)
- **재료비 = 품목단가관리 판매단가 (PR_M_ITEM_COST, COST_TAG='S', 거래처별)**
- **인상전 = 종전 판매단가 / 인상후 = 최신 판매단가**
- **역산·중량계산 안 함.** 품목단가관리에서 그대로 읽음.
- 예: MJU56925302 (Tube,Connector) → 대원산업 판매단가 19/08=**293(종전)**, 25/12=**507(인상후)**, 인상사유 비고 "원소재 사급가 변경"
- **동 정산(LME)과 무관한 부품** — 원소재 사급가 인상이 판매단가에 이미 반영돼 있어, 우리는 판매단가만 읽으면 됨.
- **품번은 원래 품목번호를 그대로 사용.** (매입처 변경 시 레거시가 접미사 품번 `MJU56925302-6-1` 생성했지만, 판매단가·사급출고는 원품번 `MJU56925302` 기준)
- 동일 구조 선례: MJC62301701 = 2959(종전)/6251(최신)

#### 2-1 인상전/인상후 기준   ✅확정 (2026-08-05)
- **인상전(종전) = 2025년 11월 또는 그 이전 판매단가** (COST_APPLY_YMD ≤ 251130 중 최신)
  - (원소재 사급가 인상이 2025-12에 반영됐으므로, 그 직전인 2025-11 이전 가격이 종전)
- **인상후(최신) = 화면 "적용월" 기준 유효 판매단가** (COST_APPLY_YMD ≤ 적용월 중 최신)
  - 적용월은 화면(리스트) 전체 선택값, 기본 당월. 예: 적용월 2026-08 → 그 시점 유효 최신가 사용
- **변형 품번 통합**: 접미사(-N-N) 붙은 조달 변형들은 **base 품번으로 묶어** 판매단가 이력을 하나로 합쳐서 종전/최신 판정
  - base 품번 자체엔 판매단가 없고 변형에만 있을 수 있음 → 반드시 base 그룹으로 조회
- 거래처: 견적서 해당 업체(협력사)의 판매단가 사용
- **예 (MJU64921201, 거래처 대원산업 2148):** 이력 418(2019-09) → 773(2025-12 "원소재 사급가 변동") → 850(2026-05)
  - 적용월 2026-08 기준 → **인상전 418 / 인상후 850**

#### 2-1 소요량·거래처·엣지케이스   ✅확정 (2026-08-05)
- (c) **재료비 = 단품(개당) 판매단가 × 소요량.** ERP(PR_M_ITEM_COST)엔 **단품가**가 저장됨. 2개 들어가면 ×2.
- (d) **판매단가 이력이 1건뿐이면(변동 없음) 인상전 = 인상후** (같은 값). 예: MJU63512516 = 791/791.
- **거래처 필터 필수**: 같은 품번이 여러 거래처에 다른 가격으로 존재. **견적서 업체(예 대원산업 2148)만** 사용.
  - 특히 **직거래(1010)** 가격은 협력사 사급가 아님 → 제외. 예: 5224A20005J 직거래1010=1528~1853 (대원2148=1008→982와 별개)
- **인상후 < 인상전(인하) 케이스도 있음** — 5224A20005J 대원 1008→982. 차이(신)이 음수로 나오는 게 정상.
- 검증 예 (대원산업, 적용월 2026-08):
  - MJU64794402: 인상전 182 / 인상후 400
  - MJU63512516: 791 / 791 (변동없음)
  - 5224A20005J: 1,008 / 982 (인하)

#### ⚠️ 구현 주의 (버그 방지)
- COST_APPLY_YMD는 **YYMMDD 6자리**(예 260526). 적용월 비교 시 반드시 YYMMDD로 (YYYYMM 비교 금지 — 2026년 가격 누락됨).

### 2-2. 동 원소재 / 제작동관 (원소재 정산 대상)   🔶일부확정 (2026-08-05)
- 판정: 견적서 col5=외경(숫자) + 사급가 7,550대. 예 MJU64794403 (6.35×0.65×71, 7,671, 재료비 57).
- **재료비 = 개당중량 × 동사급가 × 소요**
- **① 개당중량 = 견적서 "협의(합의) 치수"로 계산** ✅확정
  - geom = (외경−두께) × 두께 × π × 길이 × 8.94 ÷ 1,000,000
  - **견적서 col5/6/7(협의치수) 사용. PR_M_ITEM 손익치수 아님** (손익치수는 협의치수보다 큼 = 재료비 부풀려짐)
  - 검증: MJU64794403 → 0.00739kg × 7,671 = 57 = 견적 재료비 ✓
- **② 종전 동사급가 = 견적서 col8 (관경별, 예 7,671)** ✅확정
- **③ 신규 동사급가 = 20,000** ✅확정
- **완성 예 (MJU64794403, 적용월 2026-08):** 인상전 = 0.00739×7,671×1 = **57** (견적 일치) · 인상후 = 0.00739×20,000×1 = **148**
- **④ 고강도 판정 = `PR_M_ITEM.METAL_GUBUN='고강도'`** ✅확정
  - 레거시 w_cs_esti_010 재질 컬럼에 **"고강도 고강도관"**으로 표기됨 (일반은 재질 "동관", METAL_GUBUN='CU')
  - **동관 & METAL_GUBUN='고강도'** → 종전=견적서 col8(12k대, 예 13,028) · 신규 **22,000**
  - **동관 & METAL_GUBUN='CU'** → 종전=견적서 col8(7,550대) · 신규 **20,000**
  - 예 MJU67029602(고강도): **견적서 협의치수 6.35×0.55×128** → 0.01147kg, 종전 0.01147×13,028≈149(견적재료비 일치), 신규 0.01147×22,000≈252
  - ⚠️⚠️ **중량은 반드시 견적서 협의치수로. 레거시(w_cs_esti_010/PR_M_ITEM) 치수·중량과 다름!** (레거시 MJU67029602 길이=130, 견적서=128 → 중량 다름). 레거시 중량 절대 사용 금지.
- **동 원소재 vs 사급부품 구분 힌트**: 레거시 **단가구분 "3:소재단가" = 동 원소재**(중량×사급가). (사급부품은 다른 단가구분)
- ⚠️ 확인 필요:
  - (ii) 견적서 col8이 이미 신규가(20,000/22,000)로 갱신된 행(혼재 vintage)은 col8=종전 아님 → 이런 건 **관경별 종전 사급가 표**로 종전을 잡아야 함.

### 2-3. 용접봉   ❓확정중
- 소요 × 21,100 (추정, 확정 대기)

### 2-4. 소요량   ✅확정 (2026-08-05)
- **견적은 "단품" 단위** (예 AJR75563502-12-1). 소요량 = **단품 기준** (견적서 col13).
- **최상위 제품(AJR75563502)으로 ×N 전개하지 않음.** (최상위 전개하면 MJU64794403·5224A20005J가 ×2 되는데, 견적은 단품이라 1)
- 제작동관/사급부품 소요 = PR_M_ITEM_BOM을 **단품 레벨로** 전개(=견적서 col13과 일치).
- **용접봉은 PR_M_ITEM_BOM에 없음** → 소요를 견적서 col13(예 0.0008 = 용접ST×원단위)에서만. BOM 소요 아님(공정종속).
- ✅ 검증완료: coop_quote_part.assy_code가 **단품(-12-1) 레벨**이라 ×2 오염 없음. AJR75563502-12-1 전 부품 soyo=1, 용접봉=견적서 col13(0.00077 등). 전체 soyo≥2는 107/3146(3.4%, 단품내 실제 복수사용=정상).

### 2-5. ptype(부품종류) 재분류 필요   ⚠️미해결 (2026-08-05)
- **문제**: coop_quote_part.ptype='동관' 중 일부가 실제 **사급부품(OL)**. 예: MJU64921201·MJU64794402 = 견적서에 "사급가"로 찍힌 사급부품인데 ptype='동관'.
- **영향**: 동관으로 두면 중량×동사급가로 계산 → 판매단가로 가야 하는데 틀림.
- **판정 기준**: 견적서 col5="사급가" 텍스트 = 사급부품. col5=외경(숫자)+사급가 7,550대 = 진짜 동 원소재. (OL 12k~16k 역산값은 사급부품이므로 동관 아님)
- 재분류 규칙 확정 후 일괄 정정 예정.
