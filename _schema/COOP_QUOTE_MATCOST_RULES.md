# 협력사견적 재료비 처리 규칙 (인상전 / 인상후)

> 사용자와 **하나씩 확정하며 기록**하는 살아있는 문서. 확정 안 된 건 ❓, 확정된 건 ✅.
> 작성 시작: 2026-08-05

## 0. 목적 / 배경
- 협력사견적관리 화면에서 **재료비 = 인상전(종전) vs 인상후(현재)** 비교.
- 원소재(동) 사급가 인상이 **손익**에 미치는 영향 추적 (사급가를 낮게 주면 손익 문제).
- **원칙: 역산(재료비÷중량) 하지 않는다.** 견적서에 있는 값을 그대로 쓴다.

## 1. 견적서 파일 구조 (협력 업체 견적 정리.xlsx)
- 헤더 행4. 데이터 행5~. 시트명 = 업체.
- col2/col0 = 상위 ASSY(PART NO), col3 = 단품 품번
- col5 = 외경 **또는 텍스트("사급가"/"기존가")**, col6 = 두께, col7 = 길이
- col8 = 원소재비, col9 = 재료비, col13 = 소요량

## 2. 부품 종류별 처리 규칙

### 2-1. 사급부품 (견적서 col5 = "사급가")   ❓확정중
- 재료비 = **견적서에 표시된 사급가 값 그대로** (역산 X, 중량계산 X)
- 인상전/인상후: **(A) 인상 대상 아님 = 양쪽 동일**  vs  **(B) 판매단가 종전/최신으로 갈림** → 확인 대기

### 2-2. 동 원소재 / 제작동관   ❓확정중
- 사급가 7,550 → 20,000/22,000 인상 (이게 인상전/인상후 차이 원인)
- 계산법 상세 확정 대기

### 2-3. 용접봉   ❓확정중
- 소요 × 21,100 (추정, 확정 대기)
