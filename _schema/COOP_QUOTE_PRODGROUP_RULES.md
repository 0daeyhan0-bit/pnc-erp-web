## 가격 규칙 (담당확정 2026-07-27, ★정정됨)
- ★**매입/사급 부품 견적가 = 사급가(매출=판매내수, PR_M_ITEM_COST TAG='S') 고정값**. (매입가 아님!)
  - 예: 무플러 5256A30003U = **2,060** (25/12부터 고정, 원소재 사급가 변동으로 927→2,060).
- **매입가(TAG='1', 에프원공조 1,688~1,967 매월 변동) = 견적에 안 씀 → 수불·손익 비교용.**
- 사급가는 **변동 없이 고정**(원소재 사급가 인상 시에만 계단식 변경). 월 시세 변동분은 **수불(입출고) 정산**.
- 사급/매입 라벨 구분 없음(전부 매입품) → 가격은 **사급가(판매내수) 고정값** 사용. 무상사급=0.
- ⚠ 종전 오류: bom-form/화면이 매입가(TAG='1', pur_price)를 잡아 1,967 표기 → **TAG='S' 판매내수(사급가)로 교체 필요**.

- **매입처 선택 = "가장 최신 적용월(COST_APPLY_YMD)을 가진 매입처"** (동 시세가 계속 변하므로 현재 활성 매입처). 폐지된 매입처(사내 축관반·제이에스 등)는 제외.
  - 예: 무플러 5256A30003U → 사내·제이에스 폐지 → **에프원공조** 선택.
- **가격 = 고정** (담당확정: 사급가·매입가는 변동 없이 고정, 월 시세 안 쫓음). 무플러 = 에프원 **26/01 = 1,688 고정** (이후 26/05 1,967 등 월변동은 견적 미반영).
- **월 시세 변동분 = 수불(입출고)로 정산** (견적 재계산 안 함). 사급가·매입가 모두 고정 원칙.

## 가격 소스 (확정 대기)
- MUFFLER 5256A30003U: 엑셀 927(= 단가이력 TAG='S') vs 우리화면 1967(TAG='1'). → 사급/매입가 소스 확정 필요.
