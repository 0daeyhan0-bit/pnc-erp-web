## 1. 확정 원칙 (기록과 일치, 변경 없음)

1. **단일 BOM 유지.** 용접링은 BOM(bom_line) 부품으로 **그대로 둔다**(제거 안 함). 실측이 제거 부적합 증명.
2. **용접봉 = 공정종속**(proc_weld, kg, 관경 원단위). **용접링 = BOM 부품**(EA, 사급/매입, 규격별 개수). 둘의 축이 다름 = 기록의 설계 그대로.
3. **원가 diff0** — 155행 재료비·123행 소요·69행 협력사정산 보존이 게이트.

## 3. 봉↔링 치환 (LG=봉 → 우리=링) — 이번에 새로 정의할 부분

**문제**: LG BOM은 용접 포인트를 용접봉으로 정의. 우리는 그 포인트를 용접링으로 대체 → **그 포인트의 용접봉 소요가 줄어야** 함(사용자 확정). 용접봉 소요 정본 = nx.proc_weld.use_qty(관경 원단위×횟수×1.5, WELD_PROC_TABLES_SPEC).

**실측 상태**: 사내 28품목 중 봉소요>0 + 링 동시 = 소수(예 AJR74984301 봉0.0459·AJR75062906-SUB 봉0.0105). 나머지는 이미 봉소요=0(링만) = 이미 대체됨.

**설계(확인 필요 항목 명시)**:
- 용접링 쓰는 사내 포인트 → 용접봉 소요에서 그 몫 감소. **감소량 규칙(그 포인트 봉소요 전액 0 vs 부분)은 업무규칙 = 사용자 확인 필요**(추측 안 함).
- 정본 위치: 용접봉 소요는 proc_weld(원가). 용접링 개수는 BOM. **봉↔링 연결키(어느 링이 어느 봉포인트를 대체)는 현재 데이터에 없음 → 정의 필요.**

## 4. 삽입 ST (사내 삽입만)

- **생산 축**: "링삽입" 단품작업 이미 존재 = PR_M_WORK_SINGLE **s_work=423 (proc SW2008, 표준ST 1.5/관경)**. (실측)
- **원가 축**: routing에 삽입공정 다수 실림(52/24/77…). "용접링삽입" proc를 process_master+routing에 **신설**(제안 — 기존 삽입공정 패턴 동일). 표준 ST=1.5(423 근거).
- ★process-unify 기록대로 원가·생산 ST는 별개 → 삽입 ST를 **원가 routing에 반드시 실어야 가공비 반영**. 한쪽만 넣으면 어긋남.

## 10. ★용접봉 유형 매핑 반영 (사용자 기설명)

용접봉이 **구체코드로 흩어짐**: proc_weld(소요) 13종 ≠ nx.bom(재고) 49종, 공통 7뿐. → **유형 매핑 없이 "어느 봉 뺄지" 불가**.

**유형(사용자 정의 7종)**: 1%봉·1%와이어·2%봉·2%와이어·3%봉·3%와이어·30%봉. 각봉/원봉/와이어=%별 동일, kg단가=%로 결정(가중평균). 정본분류=WELD_TYPE_MAPPING(사용자 작성).

**매핑이 세 문제 동시 해소**: ①소요코드≠재고코드(유형이 다리) ②매니폴드 봉코드 불일치(둘 다 1%유형→실재고쪽 차감) ③봉↔링 연결(같은 %유형: 1%봉↔1%링).
