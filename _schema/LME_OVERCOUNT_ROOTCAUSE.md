# LME 과다적용 근본원인 규명 (2026-08-15)

## 결론 (한 줄)
LME 과다적용 ~6품목은 **엔진 버그가 아니라 `nx.bom_line`의 평탄화/중복 구조**(r_add_missing_edges류 손상)가 원인.
base(재료비)는 INNER_PROD 경계로 이 손상을 마스킹해 diff0이지만, `lme_total`의 별도 순회(cg5만 정지)가 손상을 그대로 노출한다.

## 증상 (260630, 실원가 오라클 대비)
| 품번 | 실원가 diff | base | LME(엔진/레거시) | 유형 |
|---|---|---|---|---|
| AJR30012101 | −605 | 정상(53,771 일치) | −1184 / −578 | 순수 LME 과다 |
| AJR30012102/103 | −606 | 정상 | 동일 | 순수 LME 과다 |
| AJR75563702 | −8,913 | 정상(34,644 일치) | −10046 / −1133 | 순수 LME 과다 |
| AJR30133607 | +12,825 | **+13,020 과다** | −1623 / −811 | base+LME 이중계상 |
| AJR30133707 | ~−140 | 근사 | −2319 / −1888 | 혼합 |

- **순수 LME형**: 중복엣지가 INNER_PROD=0(매입/외주완성) 노드 밑 → base는 매입가로 leaf 처리해 마스킹, LME만 관통 전개.
- **이중계상형**: 중복엣지가 INNER_PROD=1(사내) 노드 밑 → base도 이중 계상.

## 근본원인: nx.bom_line 평탄화/중복 (CS_M_ITEM_BOM 대비)
예 `AJR74482401-1`:
- CS(레거시 정본): `AJR74482401-1 → [AJR74482401]` (1자식) → `AJR74482401 → [AJR74482401-4-1, MJU63706901-01, RAC30599301-1]`
- nx(손상): `AJR74482401-1 → [AJR74482401-4-1, MJU63706901-01, AJR74482401]` (손자를 직접자식으로 끌어올림 + 실제자식도 유지)

→ 엔진 lme_total이 직접자식 AJR74482401-4-1을 타고 내부 동(MJU61882012 −538, MJU63706901-01 −67)까지 LME 가산.

## 스코프 (전수, 260814 기준)
- nx.bom_line "손자=직접자식" 중복패턴: **445 부모-자식쌍 / 247 부모품번** (대부분은 CS에도 있는 **정당한 구성** — 건드리면 diff0 깨짐)
- **스퓨리어스(CS에 없음, nx만 있음) = 13엣지 / 7 부모품번**, 그중 cs_calc_except=0 활성버그 = 10
  - 부모: `AJR74482401-1`, `AJR30133607`, `AJR30133707-SUB-1`, `AJR30133707-SUB-2`, (+3)
  - 목록: scratchpad/spurious_edges.json

## 왜 단순 수정이 안 되는가 (검증됨)
1. **스퓨리어스 엣지 단순 삭제 → base 붕괴.** AJR30012101에서 −28,517 소실. nx의 AJR74482401(cg='3')은 base가 leaf로 처리 → 실제 원가는 직접자식 경로가 담당. 직접자식 삭제 시 원가 소실.
2. **레거시 LME_CALC_FLAG 전파(SP line 186: 사내 노드 밑 LME OFF) 규칙을 nx 구조에 이식 → 불일치.** AJR30133607만 정확(d−0.1), 나머지 부분개선, 이미 diff0인 AJR77224002 회귀(d35). nx≠CS 구조라 규칙 이식이 깨끗이 안 됨.

## 정답 패턴 (AJR77224002 선례)
AJR77224002(MJC 이중계상)는 **중복엣지를 구조적으로 정리(삭제)해 nx를 CS와 맞춘 뒤, 엔진 무변경으로 diff0** 달성. 
→ 이 7개 부모도 **nx.bom_line 구조를 CS의 2계층 정본으로 복구**(평탄화 되돌림: 손자를 실제 부모 밑으로, cg/make_type 정합)해야 함. 엔진(lme_total) 로직은 정상이므로 손대지 않는다.

## 권고
- 이 7개 부모의 구조복구는 **sub_norm/R01 재구축(옆 세션)과 동일 성격** → 거기 합류 또는 부모 1개씩 타깃 복구 + 전수 회귀(2826품목 diff0 게이트).
- 절대 하지 말 것: 정당한 445중복(CS에도 있음) 삭제, lme_total 경계 임의 변경(회귀 유발).

## 엔진 LME 규칙 후보 전수검증 (2026-08-15, 결론=단순규칙 없음)
레거시 LME는 #TEMP_BOM→#TEMP_RESULT의 CUM_MAT_CODE 집계 bottom-set에 종속. 단순 순회규칙으로 재현 시도 모두 실패:

| 규칙 | AJR30012101 | AJR30133607 | AJR30133707 | AJR75563702 | 2826 회귀 |
|---|---|---|---|---|---|
| orig(cg5만 정지) | d−605 | d−811 | d−430 | d−8912 | 기준 |
| nested-made 차단 | **d0** | d−811 | d+1888✗ | d+961 | — |
| cg='3' 밑 차단 | **d0**(복구시) | d0(복구시) | d0(복구시) | d+788 | **회귀126/개선12** ✗ |

- **cg='3' 밑 LME 차단 규칙 = 폐기.** 138품목 변경 중 **회귀 126**(통과품목 파괴), 개선 12뿐. 레거시는 대부분 cg='3' 노드 밑 동 LME를 정상 계산함(AJR30012101은 우연 일치).
- **구조복구 효과(복구/orig엔진)**: AJR30133607(+12825→0)·AJR30133707(0) = base 이중계상형만 해결. AJR30012 계열(−538)·AJR75563702(−8912, 구조는 CS와 동일=순수 LME로직)는 **미해결**.
- **AJR75563702는 구조 정상**(CS와 RAC만 차이). 순수 LME-로직 잔차 = #TEMP_RESULT bottom-set 미묘함.

## 최종 결론 & 권고 (갱신)
1. **구조복구(7부모→CS)**: 정당·안전(nx→CS). base 이중계상형(AJR30133607류) 해결. 단 nx.bom_line은 소요/세트/kitting 공유 → 광범위 회귀검증 + sub_norm 세션 조율 필요. **엔진 무변경**.
2. **순수 LME-로직 잔차(~4품목: AJR30012101/102/103·AJR75563702)**: 단순규칙 부재 확정. **레거시 #TEMP_BOM+#TEMP_RESULT LME 로직 충실 재현**만이 정답(엔진 대공사·전수회귀 필수). ~4품목·LME성분만 → 컷오버 후 전담 태스크 권고, 또는 승인후 착수.
