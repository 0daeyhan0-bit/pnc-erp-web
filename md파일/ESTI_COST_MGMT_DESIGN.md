# 견적원가관리 (견적원가조회 → 개칭) 설계 — 확정 (2026-07-28 대표 승인)

레거시 `w_cs_esti_010`(견적원가조회) → **견적원가관리**로 진화. 개발팀 최중요 프로그램. 견적·원가 설계 워크벤치 + **외주 SUB(신규품목) 생성 원천**.

## 확정 결정 (대표 2026-07-28)
1. **원가 산출 = nx 원가엔진(NxCostEngine)만.** 레거시 SP(SP_CS_견적서_*) 미사용(권한도 없음). `_harness/nx_cost_engine.py` 재사용.
2. **신규품목/외주SUB = 자동채번**(접두어+일련).
3. **저장 = 견적 스냅샷(nx.esti_*)** 로 보관 → **"확정" 시에만 품목마스터/nx.bom 승격**(견적=시뮬레이션, 확정=승격).
4. **LG BOM 업로드 = LG BOM Explosion 엑셀**(어제 업로드분 = bom_download 산출물 LG_BOM_download/ 포맷) 드래그&드롭/파일첨부 파서.
5. **여기서 만든 SUB = 조달 프로파일 후보군으로 연결**([[newerp-sourcing-profile]] 공급처 후보).
6. **★승인 게이트(대표 2026-07-28)**: 조달 후보경로엔 **견적원가관리에서 승인받은 SUB만 노출**. status=작성→(검토)→**승인**/반려. **승인 시에만** ①품목마스터/nx.bom 승격 ②조달프로파일 후보 등록. 조달프로파일 후보목록=WHERE 승인건. **재승인**: 승인후 구성/단가/공수 변경시 status→검토 회귀→재승인(후보단가 신뢰유지). 결재(받은결재/결재대기/결재완료) 연동 가능. → 미검증 draft SUB의 조달후보 오염 방지.
   - ⚠확정필요: 승인 주체(개발팀장 단독 vs 결재선) · 재승인 트리거(변경 자동감지 vs 수동).
7. **★★미사용 SUB 전건 개발승인 필수(대표 2026-07-28)**: 견적원가관리에서 만든 것뿐 아니라 **현재 사용되지 않는 SUB는 전부 개발 승인이 있어야** 조달후보·생산에 사용 가능. **사용중(활성) SUB=그대로 사용 / 미사용·신규 SUB=미승인 상태→개발승인 전 사용불가**.
   - 구현: 품목마스터(nx.item)에 SUB **승인상태(approve_flag: 미승인/승인)** + 승인이력. 미사용 SUB는 기본 미승인. 개발이 견적원가관리(또는 품목마스터)에서 승인.
   - 영향: ①조달프로파일 후보=승인 SUB만(§연동) ②생산 편성/BOM 사용시 미승인 SUB 차단·경고 ③품목마스터 SUB 목록에 승인상태 컬럼·승인버튼. [[newerp-item-nature-reclass]](active/nature) 연계.
   - **미승인 SUB 처리방식(대표 2026-07-28)**: 상태표기=**"개발 미승인"**. ①조달후보 등 사용처=**숨김** ②품목마스터·BOM 등 조회=**보이되 읽기전용(보기만·수정불가)**. 편집·승인은 **견적원가관리(개발)에서만**. 승인되면 정상 노출·사용.

## 업무 플로우
```
① LG BOM Explosion 엑셀 드래그&드롭 → 파싱 → BOM 기본구성 + 치수/소요량 로딩(nx.lg_bom/nx.bom 참조)
② 행별 치수·소요량 편집
③ 하위행: 품목검색 drag-in(기존) OR 자동채번 신규품목 생성(외주SUB 포함)
④ 작업공수 입력(용접·체결·가공: 포인트/수·UPH·임율) → 가공비 산출(WORK_QTY÷UPH×임율, 원가엔진 규칙)
⑤ 저장 → nx.esti_*(스냅샷) + nx엔진 원가산출(재료비+가공비+LME)
⑥ "확정" → 신규 SUB를 품목마스터·nx.bom 승격 + 조달프로파일 후보 등록
```

## ★연동 수정 — 조달 프로파일(sourceprofile) (대표 2026-07-28, 화면확인)

- **미승인 SUB 후보행 = 숨기지 말고 읽기전용**(대표 지시): 하단 조달경로 후보 테이블(변형품번×공급처, 유효시작/유효종료/활성/배분% 설정)에서 **미승인 SUB 행은 입력칸 전부 읽기전용(disabled) + 상태 "개발 미승인" 표기**. **승인된 SUB만** 유효기간·활성·배분% 편집 가능.
